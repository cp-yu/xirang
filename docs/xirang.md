# Xirang Workflow

Xirang's managed workflow surface is skills-only.

## Surface

- `/xirang:propose`
- `/xirang:explore`
- `/xirang:apply`
- `/xirang:archive`
- `/xirang:build`
- `/xirang:snack`

`/xirang:archive` checks the Quality Seal and applies the Delta in the same call that archives the Change. It also supports explicit quick delivery or abandonment without applying the Delta.

## Notes

- Legacy slash command files may still exist on disk
- Xirang no longer generates, refreshes, or removes them
