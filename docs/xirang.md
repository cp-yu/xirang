# Xirang Workflow

Xirang's managed workflow surface is skills-only.

## Surface

- `/xirang:propose`
- `/xirang:explore`
- `/xirang:apply`
- `/xirang:archive`
- `/xirang:build`
- `/xirang:snack`

`/xirang:archive` runs the full verify gate before archive and performs archive-time sync inline.

## Notes

- Legacy slash command files may still exist on disk
- Xirang no longer generates, refreshes, or removes them
