## Specification

### Section: Proposal 说明动机与范围

proposal.md SHALL 说明为何发起 Change 及其范围与影响面。

- **撰写 Proposal**

  - 形成 Change Plan
  - proposal.md 记录 Change 的动机、范围与影响面

- **Proposal 不定义目标语义**

  - Change Plan 与 Semantic Delta 冲突
  - 以 Semantic Delta 为准
