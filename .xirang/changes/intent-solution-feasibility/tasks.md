## Goals

- [ ] G1: Explore 能理解不完整输入并按关键缺口推进设计
  - Contract: `explore-brainstorming` / Section "一次一问的提问纪律"
  - Verify: 只给意图、只给路线或混合表达时，识别目标与约束并澄清关键缺口；可查事实主动调查，已充分的上下文直接复用，不猜定方案或重复提问。

- [ ] G2: Explore 依据证据判断方案并恰当使用实验结果
  - Contract: `explore` / Section "委托可行性实验"
  - Verify: 同等审视用户及 Agent 方案；已有依据足够时不强制实验，关键疑点不足以判断时实践求证；局部成功保留价值但不扩大结论，失败先检查方案及假设，明确约束与目标冲突由用户裁决。

- [ ] G3: Propose 在直接入口和成文检查中保持有依据的理解与判断
  - Contract: `propose` / Section "补足最低语义就绪条件"
  - Verify: 缺少有效 Summary 时主动理解问题、目标和约束，不将路线当作完整意图；有效 Summary 得到复用；成文遇到反证时检查关键假设，不以确认代替可行性证据，不无依据重开意图确认，重大缺口按既有规则处理。

- [ ] G4: 受管提示词完整表达已确认行为并保持上下文精简
  - Contract: `explore-brainstorming` / Section "Explore 通过 referenceFiles 暴露行为引导"
  - Verify: 用户与 Agent 使用的工作面与来源一致，关键判断和边界保持完整；不出现逐阶段重复展开、固定问卷或强制实验要求，原有记录、权限和交接边界继续有效。
