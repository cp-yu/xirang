title: Quality Execution Model
definition: Quality Execution Model 定义 Apply 阶段 Quality 的 subagent-orchestrated 协作模型，独立承载主 Agent、按模式只读检查或授权实施的 Opt、只读 Reviewer 与确定性 CLI 的职责边界。主 Agent 负责范围、继续投入及最终验证判断，独立 Review 保留在 Reviewer；它不定义各角色具体评估方法或 CLI 输入形状。
